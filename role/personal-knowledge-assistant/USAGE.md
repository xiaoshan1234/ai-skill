# Personal Knowledge Assistant 使用

## 工作目录建议

- 笔记库：`~/knowledge/`（markdown + 子目录）
- 入库原始：`~/knowledge/inbox/`（待处理）
- 已处理：`~/knowledge/<topic>/<date>-<title>.md`

## 触发场景

- "读一下这篇 PDF，写笔记"
- "我之前写过关于 X 的笔记吗"
- "把这两个概念串起来"

## 笔记命名规范

`YYYY-MM-DD-<topic>-<slug>.md`，frontmatter 含 tags / source / status
